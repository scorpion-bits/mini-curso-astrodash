Introdução

Como o projeto é organizado

Managers

GameManager (Autoload): tempo, recorde, troca de cena e o aviso de game over.

Componentes

HealthComponent e HurtboxComponent: peças reutilizáveis que você encaixa em qualquer cena.

Entidades

Player e Asteroid: cada uma é uma cena independente.

Sistemas

AsteroidSpawner: cria os asteroides e controla a dificuldade.

Interface

HUD, GameOver e MainMenu: só ouvem os sinais do GameManager.

Fases

Game junta tudo: fundo, paredes, spawner, player e UI.

Por quê? Cada peça faz uma coisa só e conversa por sinais. Assim dá para adicionar inimigos, power-ups ou novas fases sem quebrar o resto.

Aula 1Etapa 1.1

Criando o projeto

  1. Abra o Godot 4 → Criar (Gerenciador de Projetos).
  2. Nome: AstroDash. Escolha uma pasta vazia.
  3. Renderizador: Forward+ (o padrão serve).
  4. Clique em Criar e Editar.
Dica Tudo dentro do projeto é acessado pelo caminho res:// (a pasta do projeto).
  1. Cena: a árvore de nós da cena aberta
  2. Arquivos: pastas e arquivos (res://)
  3. Viewport: onde você vê e arrasta as coisas
  4. Inspetor: propriedades do nó selecionado (também tem Sinais e Grupos)
  5. Telas: 2D, 3D, Script...
  6. Rodar o jogo: F5 projeto, F6 cena atual
Aula 1Etapa 1.2

Nós e cenas em 1 minuto

  • Tudo no Godot é um nó (Node). Cada tipo de nó faz uma coisa: desenhar uma imagem, colidir, tocar som, contar tempo...
  • Uma cena é uma árvore de nós salva em um arquivo .tscn.
  • Cenas podem ser instanciadas dentro de outras: a cena Game vai conter a cena Player, que por sua vez contém componentes.
  • Sinais são avisos que um nó emite ("o timer acabou", "o botão foi apertado"). Outros nós se conectam a eles.
  • Regra de ouro do curso: se dá para fazer no editor, faz no editor. Código só para lógica.
Aula 1Etapa 1.3

Configurações: tamanho da tela

  1. Projeto → Configurações do Projeto → aba Geral.
  2. Ligue Configurações Avançadas (canto superior direito).
  3. Busque size → Exibição → Janela:
  4. Largura do Viewport = 640, Altura do Viewport = 360
  5. Substituir Largura da Janela = 1280, Altura = 720
Por quê? O jogo é desenhado em 640×360 (ótimo para pixel art) e a janela abre em 1280×720 (2× maior).
Aula 1Etapa 1.4

Configurações: esticar e pixel art

  1. Busque stretch → Exibição → Janela → Esticar:
  2. Modo = canvas_items, Aspecto = keep, Modo de Escalonamento = integer
  3. Busque texture_filter → Filtro de Textura Padrão = Nearest
  4. Busque clear_color → Cor de Fundo Padrão: um azul bem escuro (ex.: #0a0819)
Por quê? Nearest deixa o pixel art nítido (sem borrar) quando a imagem é ampliada.

Aula 1Etapa 2.4

Player: script de movimento

Selecione o Player → botão Anexar Script (pergaminho com +) → salve em entities/player/player.gd. @export faz a variável aparecer no Inspetor: dá para ajustar a velocidade sem abrir o código.
entities/player/player.gd
class_name Player
extends CharacterBody2D


## Velocidade máxima da nave (pixels por segundo).
@export var speed: float = 180.0
## Quão rápido a nave acelera e freia.
@export var acceleration: float = 900.0
## Quão rápido a nave gira para a direção do movimento.
@export var rotation_speed: float = 10.0


func _physics_process(delta: float) -> void:
	var direction := Input.get_vector("move_left", "move_right", "move_up", "move_down")
	velocity = velocity.move_toward(direction * speed, acceleration * delta)
	move_and_slide()

	if direction != Vector2.ZERO:
		rotation = lerp_angle(rotation, direction.angle(), rotation_speed * delta)
Aula 1Etapa 2.5

Entendendo o movimento

  • Input.get_vector(...) junta as 4 ações num vetor de direção (já normalizado, funciona com analógico).
  • velocity.move_toward(alvo, aceleração * delta) acelera e freia suavemente, dando sensação de nave.
  • move_and_slide() move o corpo e respeita colisões (as paredes).
  • lerp_angle gira a nave aos poucos para onde ela está indo.
  • delta = tempo desde o último frame. Multiplicar por delta deixa o jogo igual em qualquer PC.
Dica Mude Speed, Acceleration e Rotation Speed no Inspetor com o jogo rodando e sinta a diferença.

Aula 1Etapa 4.1

Asteroide: um corpo físico

  1. Nova cena com raiz RigidBody2D → renomeie Asteroid. Salve em entities/asteroid/asteroid.tscn
  2. Filhos: Sprite2D (icon.svg, Scale 0.25, Modulate laranja), CollisionShape2D (círculo, raio 14) e VisibleOnScreenNotifier2D.
  3. No Asteroid: Gravity Scale = 0 (espaço não tem gravidade!).
  4. Linear → Damp Mode = Replace e Angular → Damp Mode = Replace (com Damp 0 ele não perde velocidade).
  5. Layer = 2 (asteroides), Mask = nenhuma (atravessa tudo).
Ferramenta nativa O RigidBody2D é movido pelo motor de física: a gente só dá a velocidade inicial e o Godot faz o resto, inclusive o giro.
Aula 1Etapa 4.2

Asteroide: sumir ao sair da tela (sem código!)

  1. Selecione VisibleOnScreenNotifier2D → aba Sinais.
  2. Duplo clique em screen_exited().
  3. Escolha o nó Asteroid e clique em Escolher ao lado do Método Receptor.
  4. Selecione queue_free (desligue "Somente Métodos de Script" se ele não aparecer) → Conectar.
Por quê? Sem isso, os asteroides que saem da tela continuariam existindo para sempre e o jogo ficaria lento.
Ferramenta nativa Conectamos um sinal direto a uma função que já existe em todo nó (queue_free = "me apague"). Zero linhas de código.
Aula 1Etapa 4.3

Asteroide: script

class_name Asteroid registra um tipo novo: outros scripts podem escrever var a: Asteroid. Quem chama launch() é o spawner, que diz a direção.
entities/asteroid/asteroid.gd
class_name Asteroid
extends RigidBody2D


@export var min_speed: float = 60.0
@export var max_speed: float = 120.0
## Velocidade máxima de giro (radianos por segundo).
@export var max_spin: float = 3.0


## Lança o asteroide em uma direção. Quem chama é o AsteroidSpawner.
func launch(direction: Vector2, speed_multiplier: float = 1.0) -> void:
	linear_velocity = direction * randf_range(min_speed, max_speed) * speed_multiplier
	angular_velocity = randf_range(-max_spin, max_spin)

Aula 1Etapa 5.3

Spawner: script (versão Aula 1) (1/2)

Depois de salvar, selecione o AsteroidSpawner e arraste asteroid.tscn para a propriedade Asteroid Scene no Inspetor.
systems/asteroid_spawner/asteroid_spawner.gd
class_name AsteroidSpawner
extends Node2D
## Cria asteroides em volta da tela, cruzando a tela em direções aleatórias.


@export var asteroid_scene: PackedScene

@onready var spawn_point: PathFollow2D = $SpawnPath/SpawnPoint


func _on_spawn_timer_timeout() -> void:
	spawn_point.progress_ratio = randf()
	var asteroid: Asteroid = asteroid_scene.instantiate()
	add_child(asteroid)
	asteroid.global_position = spawn_point.global_position

	var target := _pick_target()
	asteroid.launch(asteroid.global_position.direction_to(target))

Aula 2Etapa 8.1

Componentes: por quê?

  • A nave precisa de vida e de uma área que recebe dano.
  • Inimigos, chefões e escudos (no futuro) também precisam disso.
  • Em vez de copiar código, criamos componentes: nós com class_name que aparecem na janela Criar Novo Nó igual aos nós do Godot.
  • HealthComponent (Node): guarda a vida e emite died.
  • HurtboxComponent (Area2D): quando algo perigoso encosta, tira vida do HealthComponent.
Por quê? Componente bom não sabe quem é o dono. O HealthComponent não sabe que está numa nave: só avisa "morri".
Aula 2Etapa 8.2

HealthComponent (1/2)

Crie em components/health_component.gd. max_health = 1 hoje; amanhã 3 corações é só mudar no Inspetor.
components/health_component.gd
class_name HealthComponent
extends Node
## Componente de vida: guarda a vida de quem for "dono" dele e avisa quando morrer.
## Pode ser usado no player, em inimigos, em chefões...


## Emitido sempre que a vida muda (útil para barras de vida e corações).
signal health_changed(current: int, maximum: int)
## Emitido quando a vida chega a zero.
signal died

@export var max_health: int = 1

var current_health: int


func _ready() -> void:
	current_health = max_health
Aula 2Etapa 8.2

HealthComponent (2/2)

components/health_component.gd
func take_damage(amount: int) -> void:
	if current_health <= 0:
		return
	current_health = maxi(current_health - amount, 0)
	health_changed.emit(current_health, max_health)
	if current_health == 0:
		died.emit()


func heal(amount: int) -> void:
	current_health = mini(current_health + amount, max_health)
	health_changed.emit(current_health, max_health)
Aula 2Etapa 8.3

HurtboxComponent

Aqui o sinal é conectado por código porque faz parte do próprio componente: quem usa o componente não precisa lembrar de conectar nada.
components/hurtbox_component.gd
class_name HurtboxComponent
extends Area2D
## Componente "área de dano": quando um corpo perigoso encosta nele,
## tira vida do HealthComponent ligado no Inspector.


@export var health_component: HealthComponent
@export var damage_per_hit: int = 1


func _ready() -> void:
	body_entered.connect(_on_body_entered)


func _on_body_entered(_body: Node2D) -> void:
	health_component.take_damage(damage_per_hit)

Aula 2Etapa 11.1

Dificuldade com uma Curve

  • Com o tempo, os asteroides nascem mais rápido e voam mais rápido.
  • Em vez de fórmulas, usamos um recurso Curve exportado: você desenha a curva de dificuldade no Inspetor.
  • Eixo X = progresso do tempo (0 → 1 em Time To Max Difficulty segundos). Eixo Y = dificuldade (0 → 1).
  • Parte dos asteroides (Aim At Player Chance) mira na nave, usando o grupo player: ficar parado num canto não salva ninguém.
  • O grupo Dificuldade no Inspetor vem do @export_group.
Ferramenta nativa Clique na curva no Inspetor para editar: arraste os pontos, clique com o direito para adicionar. Teste curvas diferentes!

ArteEtapa 13.2

Como trocar uma arte

  1. No LibreSprite: Arquivo → Exportar → PNG na pasta assets/sprites/ do projeto.
  2. Volte ao Godot: o arquivo aparece sozinho nos Arquivos.
  3. Abra a cena (ex.: player.tscn) → selecione o Sprite2D.
  4. Arraste o PNG para Texture.
  5. Volte o Scale para (1, 1) (o 0.25 era só para o ícone de 128px).
  6. Se a arte tiver outro tamanho, ajuste o raio do CollisionShape2D.
Por quê? Como o asteroide é uma cena só, trocar a arte dele muda todos os asteroides do jogo. Essa é a vantagem de separar em cenas.
Arte

Desafios para quem terminar antes

  1. 3 vidas: max_health = 3 + mostrar corações no HUD usando o sinal health_changed.
  2. Invencibilidade por 1 segundo depois de levar dano (Timer + piscar com AnimationPlayer).
  3. Asteroides de tamanhos diferentes: crie Cenas Herdadas de asteroid.tscn com outro sprite e colisão.
  4. Power-up de escudo: um Area2D que chama heal() no HealthComponent.
  5. Som: AudioStreamPlayer para a explosão e música no menu.
  6. Tremer a tela: uma Camera2D com offset aleatório quando o player morre.

autoload/game_manager.gd

autoload/game_manager.gd
extends Node
## GameManager (Autoload): guarda o estado da partida e o recorde.
## Qualquer script do jogo pode acessar com GameManager.alguma_coisa


## Avisa que uma partida nova começou.
signal game_started
## Avisa que o jogador morreu e a partida acabou.
signal game_over

const GAME_SCENE := "res://levels/game/game.tscn"
const MENU_SCENE := "res://ui/main_menu/main_menu.tscn"
const SAVE_PATH := "user://save.cfg"

var time_survived: float = 0.0
var best_time: float = 0.0
var is_playing: bool = false


func _ready() -> void:
	load_best_time()


func _process(delta: float) -> void:
	if is_playing:
		time_survived += delta


func start_game() -> void:
	time_survived = 0.0
	is_playing = true
	game_started.emit()
func end_game() -> void:
	if not is_playing:
		return
	is_playing = false
	if time_survived > best_time:
		best_time = time_survived
		save_best_time()
	game_over.emit()


func go_to_game() -> void:
	get_tree().change_scene_to_file(GAME_SCENE)


func go_to_menu() -> void:
	is_playing = false
	get_tree().change_scene_to_file(MENU_SCENE)


func save_best_time() -> void:
	var config := ConfigFile.new()
	config.set_value("score", "best_time", best_time)
	config.save(SAVE_PATH)


func load_best_time() -> void:
	var config := ConfigFile.new()
	if config.load(SAVE_PATH) == OK:
		best_time = config.get_value("score", "best_time", 0.0)

components/health_component.gd
class_name HealthComponent
extends Node
## Componente de vida: guarda a vida de quem for "dono" dele e avisa quando morrer.
## Pode ser usado no player, em inimigos, em chefões...


## Emitido sempre que a vida muda (útil para barras de vida e corações).
signal health_changed(current: int, maximum: int)
## Emitido quando a vida chega a zero.
signal died

@export var max_health: int = 1

var current_health: int
func _ready() -> void:
	current_health = max_health


func take_damage(amount: int) -> void:
	if current_health <= 0:
		return
	current_health = maxi(current_health - amount, 0)
	health_changed.emit(current_health, max_health)
	if current_health == 0:
		died.emit()


func heal(amount: int) -> void:
	current_health = mini(current_health + amount, max_health)
	health_changed.emit(current_health, max_health)
